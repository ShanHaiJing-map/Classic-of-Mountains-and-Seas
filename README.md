# Classic-of-Mountains-and-Seas
《山海經》記錄了數以百計的山川、異獸和遠方國度，每一條都附有方位和里數，本身就是一部可以畫成地圖的書。本計劃把書中的異獸神禽和異人邦國逐條整理成資料庫，放到同一張地圖上，讓讀者按地理位置閱讀這部古籍。
The Classic of Mountains and Seas records hundreds of mountains, rivers, strange beasts, and distant kingdoms. This project aims to compile each of the strange beasts, mythical birds, and exotic peoples and kingdoms in the book into a database, placing them on a single map so that readers can explore this ancient text geographically.
